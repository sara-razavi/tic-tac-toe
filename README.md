Tic-Tac-Toe

A terminal version of Tic-Tac-Toe that I made while practicing Python.
I wanted to make something a little more like an actual game instead of only doing small exercises. Featuring: functions, lists, loops, and checking different game situations.


What it does
 
• Two players can play against each other
• Shows the game board in the terminal
• Lets players choose their positions
• Checks for a winner
• Checks for a draw

How to run
[python tic_tac_toe.py](./02_tic_tac_toe.py)
